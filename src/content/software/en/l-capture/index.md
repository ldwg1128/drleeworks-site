A simple Windows capture tool combining image and video capture with various interactive input effects.

LCapture v1.0.0 is distributed as a ZIP archive through the official DrLeeWorks GitHub Releases repository.

## Usage Examples

### 1) Image Capture

Capture any desired region on your screen directly as an image.

During area selection, use the built-in magnifier to align boundaries precisely. You can preview captured images immediately or configure automatic saving.

<!-- ![LCapture Image Capture](../../ko/l-capture/image-capture.gif) -->


### 2) Video Capture

Record designated screen areas as high-quality video clips.

Similar to image capture, area selection tools and the magnifier are available to accurately frame the recording area.

<!-- ![LCapture Video Capture](../../ko/l-capture/video-capture.gif) -->


### 3) Cursor Effects

Apply visual highlights and click animations to make mouse cursor movement and clicks easy to follow during recording.

Highlighting the cursor area and displaying click positions is especially useful when creating tutorial videos or software walkthroughs.

<!-- ![LCapture Cursor Effects](../../ko/l-capture/cursor-effects.gif) -->


### 4) Sound Effects

Add auditory feedback to mouse clicks.

You can customize sound effects and volume levels in settings to fit your recording style.

<!-- ![LCapture Sound Effects](../../ko/l-capture/sound-effects.gif) -->


### 5) Keyboard Overlay

Display real-time keyboard inputs directly on screen.

Select the target monitor and positioning, with fine-tuning controls to fit your video layout seamlessly.

<!-- ![LCapture Keyboard Overlay](../../ko/l-capture/keyboard-overlay.gif) -->


### 6) Keyboard Sound

Add satisfying sound effects to keyboard keystrokes.

Cursor Effects, Sound Effects, Keyboard Overlay, and Keyboard Sound can each be toggled independently, allowing you to use only the effects you need.

<!-- ![LCapture Keyboard Sound](../../ko/l-capture/keyboard-sound.gif) -->


### 7) Compact Floating Interface

LCapture operates as a compact floating toolbar that minimizes desktop footprint.

Easily access core features like Image, Video, Cursor Effects, and Settings, and expand detailed options only when needed.

<!-- ![LCapture Interface](../../ko/l-capture/interface.gif) -->


### 8) Other Features

- Instant image preview after capture
- Automatic image saving
- Auto-hide window during capture
- Region selection for images and videos
- Magnifier support for boundary alignment
- Individual toggles for Cursor Effects
- Individual toggles for Mouse Sound Effects
- Individual toggles for Keyboard Overlay
- Individual toggles for Keyboard Sound
- Granular settings per input effect
- System tray support
- Minimal floating UI
