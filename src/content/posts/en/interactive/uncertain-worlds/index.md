## Simple Rules, Uncertain Worlds

This demo is not a scripted animation designed to produce a particular shape or ideal outcome. It defines only weak attraction, short-range repulsion, small stochastic force, and probabilistic bond formation and breaking, then displays the resulting time evolution.

Run the same setup more than once, or enter a seed to revisit a world you found earlier. The same seed and parameters reproduce the same initial state and, as far as the browser timing permits, the same simulation. Set `Randomness` to 0 to compare the system without stochastic force.

<!-- interactive:uncertain-worlds -->

This is not a simulation of quantum mechanics. It is a small computational experiment for observing what structures form, grow, break down, and reconnect when stochastic fluctuation is added to a simple rule-based system. It includes no arbitrary complexity score or rule that forces a particular pattern.
