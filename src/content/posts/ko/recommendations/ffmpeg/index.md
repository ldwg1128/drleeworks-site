# FFmpeg

FFmpeg는 **영상과 음성을 변환, 처리, 녹화, 스트리밍할 수 있는 오픈소스 멀티미디어 프레임워크**이다.

MP4, MKV, AVI, MOV, MP3, WAV 등 다양한 미디어 형식과 코덱을 지원하며, 단순한 파일 형식 변환부터 영상 자르기, 압축, GIF 생성, 음원 추출, 화면 녹화 등 다양한 작업을 수행할 수 있다.

FFmpeg는 일반적인 GUI 프로그램과 달리 **명령줄(Command Line Interface, CLI)**을 중심으로 동작한다. 따라서 처음 접하면 다소 어렵게 느껴질 수 있지만, 명령어를 이용하여 반복적인 작업을 자동화하기 쉽고 다른 프로그램에서 미디어 처리 엔진으로 활용하기에도 적합하다.

이러한 특징 때문에 FFmpeg는 다양한 영상·음성 관련 소프트웨어의 내부 엔진으로 널리 사용되고 있으며, DrLeeWorks에서 개발하는 여러 프로그램에서도 미디어 처리를 위해 활용하고 있다.

FFmpeg 및 FFmpeg를 활용하여 제작된 소프트웨어는 아래 링크에서 다운로드할 수 있다. 특히 DrLeeWorks에서 제작한 일부 소프트웨어는 FFmpeg를 외부 미디어 처리 엔진으로 사용하므로 **FFmpeg가 설치되어 있어야 모든 기능이 정상적으로 작동한다.**

또한 Windows에서 FFmpeg를 설치하는 경우 FFmpeg 실행 파일이 위치한 경로를 **시스템 PATH 환경 변수에 등록하는 것을 권장한다.** PATH가 정상적으로 설정되어 있으면 특정 폴더로 이동하지 않고도 터미널이나 다른 프로그램에서 `ffmpeg` 명령을 호출할 수 있다.

## 1. FFmpeg 개요

FFmpeg는 영상과 음성을 처리하기 위한 대표적인 오픈소스 멀티미디어 프로젝트이다.

주요 특징은 다음과 같다.

- 다양한 영상 및 음성 형식을 지원한다.
    
- Windows, Linux, macOS 등 여러 운영체제에서 사용할 수 있다.
    
- 명령줄(CLI)을 기반으로 동작한다.
    
- 영상과 음성의 변환, 편집 및 분석이 가능하다.
    
- 반복적인 미디어 처리 작업을 자동화하기 쉽다.
    
- 다른 프로그램의 미디어 처리 엔진으로 활용할 수 있다.
    
- 오픈소스로 제공되어 다양한 소프트웨어 및 개발 프로젝트에서 활용되고 있다.
    

FFmpeg의 가장 큰 특징 중 하나는 **터미널에서 명령어를 입력하여 동작한다는 점**이다.

예를 들어 다음과 같이 간단한 명령 하나만으로 MKV 영상을 MP4 형식으로 변환할 수 있다.

```bash
ffmpeg -i input.mkv output.mp4
```

여기서 `-i`는 입력 파일(input)을 지정하는 옵션이다.

처음에는 명령어 방식이 불편하게 느껴질 수 있지만, 이러한 구조 덕분에 FFmpeg는 다른 프로그램에서 필요한 명령을 자동으로 실행하는 **백엔드 미디어 처리 엔진**으로 사용하기에 매우 적합하다.

## 2. FFmpeg로 할 수 있는 것

FFmpeg를 이용하면 다양한 영상 및 음성 처리 작업을 수행할 수 있다.

- 영상 및 음성 형식 변환
    
- 영상 자르기 및 특정 구간 추출
    
- 영상 크기 및 해상도 변경
    
- 영상 압축 및 용량 감소
    
- 영상에서 음원 추출
    
- GIF 생성
    
- 화면 및 장치 녹화
    
- 영상과 음성 결합
    
- 자막 처리
    
- 영상 프레임 추출
    
- 프레임 레이트(FPS) 변경
    
- 코덱 변환
    
- 영상 회전 및 크롭
    
- 여러 미디어 파일의 일괄 처리
    
- 영상 및 음성 스트리밍
    

따라서 FFmpeg는 단순한 '영상 변환 프로그램'이라기보다 **멀티미디어 파일을 처리하기 위한 종합적인 도구**에 가깝다.

## 3. FFmpeg의 주요 구성 요소

FFmpeg 프로젝트에는 미디어를 처리하고 분석하기 위한 여러 도구가 포함되어 있다.

### FFmpeg

영상과 음성을 변환하고 처리하는 핵심 명령줄 도구이다.

파일 형식 변환, 영상 자르기, 압축, GIF 생성, 음원 추출 등 대부분의 미디어 처리 작업을 담당한다.

### FFprobe

영상 및 음성 파일의 정보를 분석하는 도구이다.

다음과 같은 정보를 확인할 수 있다.

- 영상 및 음성 코덱
    
- 해상도
    
- FPS
    
- 재생시간
    
- 비트레이트
    
- 오디오 채널
    
- 스트림 정보
    
- 메타데이터
    

프로그램에서 미디어 파일을 불러올 때 파일의 특성을 자동으로 분석하는 용도로도 활용할 수 있다.

### FFplay

FFmpeg 라이브러리를 기반으로 동작하는 간단한 미디어 플레이어이다.

복잡한 미디어 플레이어 기능보다는 FFmpeg를 이용하여 영상이나 음성을 빠르게 확인하거나 테스트할 때 유용하다.

## 4. 왜 많은 프로그램에서 FFmpeg를 사용하는가?

FFmpeg는 다양한 미디어 형식을 지원하며 높은 성능과 뛰어난 확장성을 제공한다.

주요 장점은 다음과 같다.

- 다양한 미디어 형식을 지원한다.
    
- 다양한 영상 및 음성 코덱을 지원한다.
    
- 영상 및 음성 처리 성능이 뛰어나다.
    
- 명령줄을 이용한 자동화가 쉽다.
    
- 다른 프로그램에서 호출하여 사용할 수 있다.
    
- Windows, Linux, macOS를 지원한다.
    
- 오픈소스로 제공된다.
    
- 복잡한 미디어 처리 기능을 직접 처음부터 구현할 필요가 없다.
    

FFmpeg 자체는 명령줄 기반 도구이지만 Python을 비롯한 여러 프로그래밍 언어에서 FFmpeg 프로세스를 호출할 수 있다.

예를 들어 사용자가 GUI 프로그램에서 **영상 자르기** 버튼을 누르면 프로그램 내부에서 FFmpeg 명령을 자동으로 생성하여 실행하도록 만들 수 있다.

즉,

**사용자 → 프로그램 GUI → FFmpeg → 영상 처리**

와 같은 구조로 사용할 수 있다.

이 방식을 이용하면 사용자는 FFmpeg 명령어를 직접 입력할 필요 없이 일반적인 프로그램처럼 버튼을 클릭하여 FFmpeg의 강력한 미디어 처리 기능을 사용할 수 있다.

DrLeeWorks에서 개발하는 일부 프로그램 역시 이러한 방식으로 FFmpeg를 활용한다.

## 5. 간단한 사용 예

FFmpeg의 기본적인 사용 방법을 몇 가지 예를 통해 살펴보면 다음과 같다.

### 영상 형식 변환

터미널에서 아래 명령을 실행하면 `input.mkv` 파일을 `output.mp4` 파일로 변환한다.

```bash
ffmpeg -i input.mkv output.mp4
```

FFmpeg가 입력 파일의 미디어 정보를 분석하고 출력 파일의 확장자와 옵션에 따라 적절한 형식으로 변환한다.

---

### 영상의 특정 구간 자르기

다음 명령은 영상의 10초 지점부터 20초 동안의 구간을 추출한다.

```bash
ffmpeg -ss 00:00:10 -i input.mp4 -t 00:00:20 output.mp4
```

`-ss`는 시작 위치를 의미하고 `-t`는 추출할 구간의 길이를 의미한다.

이러한 기능을 GUI 프로그램과 결합하면 사용자가 시작점과 종료점을 선택한 뒤 버튼 하나로 원하는 부분만 저장하는 기능을 구현할 수 있다.

---

### 영상에서 음원 추출

영상에서 오디오만 MP3 파일로 추출할 수도 있다.

```bash
ffmpeg -i input.mp4 output.mp3
```

영상 파일의 오디오 스트림을 이용하여 별도의 음원 파일을 생성한다.

---

### 영상을 GIF로 변환

FFmpeg를 이용하면 영상의 특정 구간을 GIF 애니메이션으로 변환할 수도 있다.

예를 들어 다음 명령은 영상의 5초 지점부터 3초 동안의 영상을 GIF로 만든다.

```bash
ffmpeg -ss 00:00:05 -t 3 -i input.mp4 output.gif
```

단순 변환도 가능하지만 GIF는 일반적인 영상 코덱을 사용하지 않기 때문에 해상도와 FPS가 높으면 파일 용량이 매우 커질 수 있다.

따라서 웹사이트에 사용할 GIF라면 크기와 FPS를 줄여 변환하는 것이 효율적이다.

예를 들어 다음과 같이 사용할 수 있다.

```bash
ffmpeg -ss 00:00:05 -t 3 -i input.mp4 -vf "fps=12,scale=720:-1" output.gif
```

이 명령에서는 GIF의 프레임 레이트를 12 FPS로 설정하고 가로 해상도를 720 px로 조정한다. 세로 해상도는 원본 영상의 비율에 맞추어 자동으로 결정된다.

이 기능은 프로그램의 짧은 사용 예나 기능 소개를 웹사이트에 GIF 형태로 게시할 때 유용하다.

---

### 영상의 해상도 변경

영상의 크기를 변경할 수도 있다.

```bash
ffmpeg -i input.mp4 -vf scale=1280:720 output.mp4
```

위 명령은 영상을 1280 × 720 해상도로 변환한다.

---

### 영상에서 이미지 프레임 추출

영상의 프레임을 이미지로 저장할 수도 있다.

```bash
ffmpeg -i input.mp4 frame_%04d.png
```

실행하면 영상의 각 프레임이 다음과 같은 형태로 저장된다.

```text
frame_0001.png
frame_0002.png
frame_0003.png
...
```

영상 분석이나 특정 장면을 이미지로 추출할 때 활용할 수 있다.

---

### 영상 정보 확인

FFmpeg와 함께 제공되는 FFprobe를 사용하면 영상 파일의 정보를 확인할 수 있다.

```bash
ffprobe input.mp4
```

코덱, 해상도, FPS, 재생시간, 오디오 스트림 등 다양한 정보를 터미널에서 확인할 수 있다.

---

위와 같이 많은 사용 예가 있지만, 전문가가 아닌 이상 모든 명령어를 기억할 수 없다.

하지만, 요즘은 클로드 코드, Codex 등 AI agent에 FFmpeg가 설치되어 있음을 명시하고 자연어로 필요한 기능을 요청만 해도 잘 작동한다.

또한 특정 기능을 수행하기 위한 명령어를 프롬프트로 요청할수도 있다.

## 6. FFmpeg와 GUI 프로그램

FFmpeg는 매우 강력하지만 기본적으로 명령줄 기반이기 때문에 일반 사용자가 모든 명령어와 옵션을 직접 기억하여 사용하는 것은 불편할 수 있다.

하지만 이러한 특성은 오히려 프로그램 개발 측면에서는 큰 장점이 된다. **필자는 오히려 이러한 점 때문에 다양한 소프트웨어의 개발에 적극적으로 활용하고 있다.**

개발자는 FFmpeg 명령을 프로그램 내부에 구현하고 사용자는 GUI에서 필요한 기능만 선택하도록 만들 수 있다.

예를 들어 프로그램에서 사용자가

1. 영상을 선택하고
    
2. 시작점과 종료점을 지정하고
    
3. `Trim` 버튼을 누르면
    

프로그램 내부에서 FFmpeg가 자동으로 실행되어 해당 구간을 새로운 영상으로 저장하도록 만들 수 있다.

GIF 생성, 영상 압축, 해상도 변경, 프레임 추출 등의 기능도 같은 방식으로 구현할 수 있다.

따라서 FFmpeg는 사용자가 직접 사용하는 도구인 동시에 **다른 멀티미디어 프로그램의 기능을 구현하기 위한 기반 엔진**으로서도 중요한 역할을 한다.

## 7. 정리

FFmpeg는 영상과 음성을 다루는 데 필요한 다양한 기능을 하나의 프로젝트에서 제공하는 강력한 오픈소스 멀티미디어 프레임워크이다.

단순한 영상 형식 변환뿐만 아니라 영상 자르기, 압축, GIF 생성, 음원 추출, 프레임 추출, 녹화, 스트리밍 등 매우 다양한 작업에 활용할 수 있다.

특히 명령줄 기반이라는 특징 덕분에 자동화가 쉽고 다른 프로그램의 내부 기능으로 연결하기도 좋다.

DrLeeWorks에서도 이러한 장점을 활용하여 영상 및 화면 처리 기능이 필요한 자체 제작 소프트웨어에 FFmpeg를 적용하고 있으며, 앞으로 개발되는 관련 프로그램에서도 활용할 예정이다.
