GPT-6 아스트라가 직접 블렌더를 제어하여 모델링을 할 수 있다고 한다. 공개된 예시에서는 화려하고 복잡한 결과물이 주로 보었는데 저게 진짜 가능할까 하는 생각이 들었다. 그래서 간단한 블렌더 모델 제작을 자연어로 직접 해보면서 이게 사실인지 확인해보고자 하였다.

## 준비

현 시점에는 GPT-6 아스트라가 출시된지 얼마 되지않아 유료사용자에게 순차적으로 배포된다고 한다.

필자의 경우에도 웹에서는 5.6 Sol 모델만 보였는데, [ChatGPT 데스크톱 앱](https://chatgpt.com/download/)을 설치하니 앱에서는 아스트라의 사용이 가능해서 바로 시도해보았다.

[블렌더 최신버전](https://www.blender.org/download/)이 설치된 환경에서 Chat GPT 데스크톱 앱 설치 및 실행 후 Codex에 자연어로 블렌더로 모델링을 해달라는 요청을 하였다.


## 아스트라로 모델링 해보기


블렌더 최신버전이 설치된 환경에서 아스트라에 아래와 같은 요청을 하였다.
*국제시험규격중 하나인 ASTM D3039는 고분자 복합재료의 인장 특성(Tensile Properties)을 측정하는 대표적인 시험 표준이다. 특히 섬유강화 복합재료(FRP)에 널리 사용된다.*

> **Prompt**
>
> 블렌더를 열어서 ASTM D3039 규격에 나오는 인장시험 시편을 모델링 해줘. 여러 치수중에 Symmetry 조건인 경우에 대해서 모델링 해주고, 시편과 탭 색상도 실제와 유사하게 구분해줘.


요청 후 응답은 아래와 같았다. 

명령 실행과 파일 저장 도구가 모두 오류여서 직접 Blender를 컨트롤 할 수 없으니 스크립트를 제공해 주겠다. 이것을 너가 직접 블렌더에서 사용해라.

## 오류 수정과 추가 요청

조금전의 모델 생성은 실질적으로는 스크립트를 제공받아 수행한 것이라서 이전 모델에서도 충분히 가능한 방법이다. 따라서 초기 오류를 해결함으로써 아스트라가 직접 블렌더를 다루게 하기로 하였다.

한참을 씨름한 끝에 임시폴더 권한과 관련된 오류로 밝혀졌고, 사용할 임시폴더의 위치를 바꾸니 해결되었다. 이는 Docker라는 프로그램을 사용할때도 발생했던 문제인데, 구글링이나 AI를 이용하여 아무리 해결하려고 해도 해결되지 않던 문제이다.

## 아스트라를 이용한 색감과 뷰의 조정

모델을 처음부터 다시 만들어 달라고 하지는 않았고, 이미 모델이 만들어진 상태에서, 원하는 모습에 조금 더 가깝게 만들기 위한 요청을 이어갔다.

블렌더는 카메라와 조명도 직접 설치를 해야 카메라 방향에 따라 모델이 Modeling 탭에서 보여진다.

카메라와 조명을 직접 달기 귀찮으니 "Modeling 탭에서 현재 만들어진 모델을 ISO 뷰로 보여줘"라는 취지로 요청을 하였다.

그러자 아스트라가 컴퓨터를 제어하면서 카메라를 새로 만들고 뷰 까지 알아서 잡아주었다.

그러나 뒷 배경이 검정색이고 조명도 없어서 여전히 많이 어색하다.


![오류 해결 후 ISO 요청 화면](./image06.png)
![ISO 표시 화면](./image07.png)

다시 "배경과 색감도 좀 더 자연스럽게 바꿔달라"고 요청하였다.

이때부터는 아스트라가 직접 컴퓨터를 제어하면서 블렌더를 조작하였다. 모니터 가장자리가 파란색으로 바뀌고 마우스 커서가 알아서 움직이는 모습이 꽤 신기했다.

이때 여전히 사용자가 마우스와 키보드를 자유롭게 사용할수는 있지만 그러면 아스트라가 작업을 중단해버린다. 그래서 멍하니 직접 수정하는것을 구경하고 있어야 한다.

![GPT가 화면 제어하는 모습](./image08.png)
*GPT가 컴퓨터 제어 중 카메라를 이용한 촬영 화면. 화면 캡쳐로는 파란색 테두리가 나오지 않는다.*

## 최종 결과

결과적으로 블렌더의 기능이나 코드를 하나하나 찾아가며 수정하기보다는, **문제가 생기면 보여주고 고쳐달라고 하고, 마음에 들지 않는 부분은 다시 요청하는 방식**만으로 최종 렌더링이 가능한 상태까지 아래 그림과 같이 만들 수 있었다.

이렇게 만들어진 모델은 AI로 생성한 이미지에 비해 훨씬 정교하며 직접 모델링 하는것 보다는 훨씬 빠르고, 무엇보다도 머리 아프게 블렌더를 붙잡고 있지 않아도 되기 때문에 앞으로 매우 자주 사용하게 될 거 같다.
