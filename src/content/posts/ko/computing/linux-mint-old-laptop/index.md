Linux라는 운영체제의 이름은 오래전부터 알고 있었지만 직접 사용해 본 적은 없었다.

과거 Linux를 사용하는 모습을 몇 번 본 적이 있는데, DOS의 명령 프롬프트처럼 보이는 터미널에 여러 명령어를 입력하는 모습이 상당히 복잡해 보였다. 당시에는 일반 사용자가 접근하기 어려운 운영체제라는 인상이 강했다.

그러다 구형 컴퓨터에 Linux를 설치하면 비교적 쾌적하게 사용할 수 있고, Windows와 비슷한 그래픽 인터페이스를 제공하는 배포판도 있다는 것을 알게 되었다.

마침 성능 문제로 사용하지 않고 방치해 둔 오래된 노트북이 있어 **Linux Mint**를 직접 설치해 보았다.

> 이 글은 2024년 8월에 구형 노트북에 Linux Mint를 처음 설치하고 사용해 본 경험을 바탕으로 작성한 기록이다.

---

## Linux Mint 선택

Linux는 하나의 완성된 운영체제 제품이라기보다 Linux 커널을 기반으로 여러 종류의 배포판이 존재한다.

그중 처음 사용하는 사람에게 비교적 친숙하다고 알려진 **Linux Mint**를 선택하였다.

Linux Mint에서도 여러 데스크톱 환경을 선택할 수 있는데, 이번에는 **Cinnamon Edition**을 설치하였다. Cinnamon은 시작 메뉴, 작업 표시줄, 파일 탐색기 등의 구성이 Windows와 상당히 비슷하여 기존 Windows 사용자라면 적응하기 쉽다.

<!-- ![Linux Mint 요구 사양](0 요구사양.png) -->

Linux Mint는 비교적 낮은 사양의 컴퓨터에서도 사용할 수 있다.

더 오래된 컴퓨터에서 시스템 자원 사용량을 줄이고 싶다면 Cinnamon보다 가벼운 **Xfce Edition**도 선택할 수 있다. 다만 단순히 오래된 컴퓨터라는 이유만으로 반드시 Xfce를 선택할 필요는 없으며, 어느 정도 사양이 된다면 Cinnamon도 충분히 사용할 만하다.

## 설치 USB 만들기

Linux Mint 공식 홈페이지에서 ISO 이미지를 내려받아 부팅 가능한 USB를 만들 수 있다.

<!-- ![Linux Mint ISO 다운로드](1 ISO.png) -->

ISO 파일을 USB에 단순히 복사하는 것이 아니라 부팅 가능한 형태로 기록해야 한다.

Linux Mint 홈페이지에서도 이러한 작업에 사용할 수 있는 프로그램을 안내하고 있어 처음 설치하더라도 크게 어렵지는 않았다.

<!-- ![ISO 이미지 USB 기록](2 ISO burning.png) -->

설치 USB를 만든 후 노트북을 USB로 부팅하면 Linux Mint 설치를 시작할 수 있다.

## Linux Mint 설치

설치 과정 자체는 어렵지 않았다.

다만 사용한 노트북이 오래된 제품이어서 그런지 설치 완료까지는 생각보다 시간이 걸렸다.

<!-- ![Linux Mint 설치 화면](KakaoTalk_20240807_132451642_04.jpg) -->

<!-- ![Linux Mint 설치 과정](KakaoTalk_20240807_132451642.jpg) -->

설치 과정에서는 언어와 키보드, 저장장치 등을 설정할 수 있으며 필요에 따라 멀티미디어 코덱도 함께 설치할 수 있다.

설치 후에는 Linux에서 지원되는 하드웨어의 상당수가 자동으로 인식되지만, 모든 장치가 항상 자동으로 동작하는 것은 아니다.

실제로 이 노트북에서는 Wi-Fi가 처음부터 정상적으로 인식되지 않았다.

---

## 첫 부팅과 Wi-Fi 문제

설치가 끝난 후 부팅한 화면은 상당히 단순하고 깔끔하였다.

<!-- ![Linux Mint 첫 실행 화면](KakaoTalk_20240807_132610502.jpg) -->

인터페이스가 Windows와 상당히 비슷하다.

화면 아래에는 작업 표시줄이 있고 왼쪽에는 시작 메뉴와 비슷한 메뉴가 존재한다. 기본 웹 브라우저로 Firefox도 설치되어 있어 운영체제를 설치한 직후 바로 웹을 사용할 수 있다.

다만 앞서 언급했듯 이 노트북에서는 Wi-Fi 장치가 자동으로 잡히지 않았다.

처음에는 별도의 컴퓨터에서 드라이버를 찾아야 하나 싶었지만, 설치에 사용했던 USB를 다시 연결하고 드라이버 관련 설정을 확인하면서 Wi-Fi 모듈용 드라이버를 설치할 수 있었다.

별도의 드라이버 파일을 인터넷에서 직접 찾아 내려받지 않고 설치 USB를 이용하여 해결할 수 있었다는 점은 의외로 편리했다.

## 오래된 노트북에서의 성능

사용한 노트북의 CPU는 **Intel Core i3-4005U**이다.

<!-- ![시스템 정보](KakaoTalk_20240807_132451642_03.jpg) -->

최신 기준으로는 상당히 오래된 CPU이지만 Linux Mint에서 웹 브라우징, 간단한 문서 작업, 동영상 재생과 같은 기본 작업을 수행하는 데에는 생각보다 큰 문제가 없었다.

특히 기존에 느꼈던 오래된 컴퓨터 특유의 답답함이 상당히 줄어들었다.

물론 Linux를 설치한다고 CPU나 저장장치 자체의 성능이 높아지는 것은 아니다. 다만 비교적 가벼운 운영체제와 백그라운드 환경 덕분에 구형 하드웨어에서도 기본적인 작업을 수행하기 좋은 환경을 만들 수 있다는 점이 장점이다.

---

## 파일 관리와 기본 프로그램

파일 관리자를 열어 보면 Windows를 사용하던 사람에게 상당히 익숙한 구성을 볼 수 있다.

<!-- ![Linux Mint 파일 관리자](KakaoTalk_20240807_132451642_02.jpg) -->

왼쪽에 바탕화면, 문서, 음악, 사진, 비디오, 다운로드 등의 항목이 배치되어 있어 Windows 파일 탐색기와 사용 방식이 크게 다르지 않다.

기본적인 사진, 음악, 동영상 관련 프로그램도 함께 제공된다.

당시 사용하면서 확인한 사소한 문제로는 GIF 이미지를 기본 이미지 프로그램으로 열었을 때 애니메이션이 재생되지 않는 경우가 있었다. 다만 Linux에서는 기본 프로그램을 다른 프로그램으로 쉽게 대체할 수 있으므로 큰 문제는 아니었다.

---

## LibreOffice를 이용한 문서 작업

Linux Mint에는 **LibreOffice**를 사용할 수 있다.

LibreOffice는 무료 오픈소스 오피스 프로그램으로 문서, 스프레드시트, 프레젠테이션 등을 작성할 수 있으며 Microsoft Office 형식의 파일도 불러오거나 저장할 수 있다.

따라서 간단한 문서 작성이나 일반적인 사무 작업이라면 별도의 유료 Office 프로그램 없이도 상당 부분 해결할 수 있다.

다만 Microsoft Office와 완전히 동일한 프로그램은 아니기 때문에 복잡한 서식, 매크로 또는 특정 기능을 사용하는 문서는 호환성을 확인할 필요가 있다.

---

## Inkscape 설치

평소 사용하는 프로그램 중 하나인 **Inkscape**도 Linux 버전이 있어 설치해 보았다.

<!-- ![Linux에서 실행한 Inkscape](KakaoTalk_20240807_132451642_01.jpg) -->

실행 속도도 빠르고 기본적인 작업에는 별다른 문제가 없었다.

Linux라고 해서 터미널 프로그램만 사용하는 것은 아니며, 실제로는 웹 브라우저, 그래픽 프로그램, 미디어 플레이어, 문서 작성 프로그램 등 상당수의 작업을 일반적인 GUI 환경에서 수행할 수 있다.

---

## Software Manager

Linux Mint에는 **Software Manager**가 제공된다.

스마트폰의 앱스토어나 Windows의 Microsoft Store와 비슷하게 프로그램을 검색하고 설치할 수 있는 기능이다.

사용 가능한 상용 프로그램의 종류는 Windows보다 적지만, Linux를 지원하는 프로그램은 Software Manager를 통해 상당히 편리하게 설치할 수 있다.

처음 Linux를 사용하기 전에는 프로그램 하나를 설치하려면 터미널에 복잡한 명령어를 입력해야 할 것이라고 생각했는데, 실제로는 Software Manager만으로 해결되는 경우도 많았다.

---

## 터미널에 대한 인상이 바뀌다

처음 Linux를 꺼렸던 가장 큰 이유 중 하나가 터미널이었다.

그런데 직접 사용해 보니 오히려 재미있는 부분도 있었다.

예를 들어 패키지 정보를 갱신하고 설치된 패키지를 업데이트하려면 다음과 같은 명령을 사용할 수 있다.

```bash
sudo apt update
sudo apt upgrade
```

명령어 몇 줄을 입력하면 필요한 파일들이 자동으로 내려받아지고 설치되는 과정이 터미널에 표시된다.

Windows에서는 보통 웹사이트를 찾아가 설치 파일을 내려받고 실행하는 방식에 익숙했기 때문에, 처음에는 명령어 하나로 프로그램이나 기능이 설치되는 방식 자체가 상당히 신기하게 느껴졌다.

물론 모든 작업에 터미널이 필요한 것은 아니다. Linux Mint에서는 많은 작업을 그래픽 인터페이스만으로 처리할 수 있으며, 필요할 때 터미널을 이용하면 더 빠르고 편리한 경우가 있다고 이해하는 편이 적절하다.

## 한/영 전환 문제

한국어 환경에서는 한/영 입력 설정이 약간 번거로울 수 있었다.

처음 설치했을 때 노트북의 한/영 전환키가 바로 동작하지 않아 관련 입력 기능을 추가로 설치하고 설정해야 했다.

관련 정보를 찾아 터미널에서 필요한 패키지를 설치한 뒤 입력기 설정을 변경하여 해결하였다.

이 과정은 Windows보다 다소 번거롭게 느껴졌지만, 한 번 설정한 이후에는 정상적으로 사용할 수 있었다.

---

## 한컴오피스는 아쉬운 부분

문서 작업 측면에서 가장 아쉬웠던 부분은 한컴오피스였다.

LibreOffice가 있어 일반적인 문서 작업에는 큰 문제가 없었지만, 국내에서 많이 사용하는 HWP 문서를 다뤄야 하는 경우에는 선택지가 제한적이었다.

당시 Linux용 한컴오피스를 공식적으로 일반 Windows 프로그램처럼 사용할 수 있는 환경은 아니었으며, Linux에서 사용할 수 있다는 한글 뷰어도 찾아보았지만 이 노트북에서는 정상적으로 설치하지 못했다.

따라서 **HWP 문서를 자주 작성하거나 완벽한 호환성이 필요한 사용자라면 Linux로 완전히 전환하기 전에 확인이 필요하다.**

## 기본 스크린샷 기능

Print Screen 키를 눌러 기본 스크린샷 기능도 사용해 보았다.

<!-- ![Linux Mint 스크린샷 기능](스크린샷, 2024-08-09 09-10-25.png) -->

캡처한 이미지를 클립보드에 복사하거나 파일로 저장하는 등의 기능을 간단한 인터페이스에서 선택할 수 있었다.

사소한 기능이지만 전체적으로 인터페이스가 깔끔하고 필요한 기능을 어렵지 않게 찾을 수 있다는 점이 마음에 들었다.

## 총평

구형 컴퓨터를 어떻게든 다시 활용하고 싶다면 **Linux Mint는 충분히 시도해 볼 만한 무료 운영체제**라고 생각한다.

직접 사용해 본 범위에서는 다음과 같은 기본적인 용도에 큰 문제가 없었다.

* 웹서핑 및 YouTube 시청
* 문서 작성 및 간단한 사무 작업
* 사진 및 동영상 감상
* Inkscape와 같은 Linux 지원 프로그램 사용
* 파일 관리와 일반적인 데스크톱 작업

특히 오래되어 Windows에서는 다소 답답했던 노트북에서도 기본적인 작업이 비교적 빠릿빠릿하게 동작한다는 점이 인상적이었다.

다만 **Linux가 무조건 Windows보다 빠르다거나 모든 오래된 컴퓨터를 되살릴 수 있다는 의미는 아니다.** 사용하는 하드웨어의 Linux 드라이버 지원 여부와 필요한 프로그램이 Linux를 지원하는지를 먼저 확인하는 것이 좋다.

Windows 전용 프로그램을 많이 사용한다면 완전한 대체 운영체제로 사용하기에는 불편할 수 있다. 반대로 웹 브라우징, 동영상 시청, 간단한 문서 작성처럼 범용적인 작업이 주목적이라면 생각보다 부족함이 적다.

더 오래된 컴퓨터라면 Cinnamon보다 시스템 자원을 적게 사용하는 **Linux Mint Xfce Edition**도 좋은 선택지가 될 수 있다.

처음에는 Linux라고 하면 터미널에 알 수 없는 명령어를 계속 입력해야 하는 운영체제라는 이미지가 강했다. 그러나 실제로 Linux Mint를 사용해 보니 대부분의 일상적인 작업은 Windows와 크게 다르지 않은 그래픽 환경에서 처리할 수 있었다.

**버리기는 아깝고 Windows를 사용하기에는 버벅이는 노트북이나 데스크톱이 있다면 한 번쯤 설치해 볼 만하다.**

오래된 컴퓨터 한 대를 다시 사용할 수 있게 만드는 것만으로도 Linux Mint를 경험해 볼 이유는 충분하였다.
